\section{Executive Summary}
% =========================================================

AETHER-OS is a local-first personal operating system built with Rust (Tauri v2) and React 19. It combines knowledge management, AI-assisted thinking, project orchestration, and persistent memory into a single desktop application that runs entirely on the user's machine.

\textbf{The thesis:} The productivity software market is splitting into two camps --- cloud-locked SaaS (Notion, \$600M ARR, 100M users) and local-first sovereign tools (Obsidian, \$25M ARR, 1.5M users, zero VC). AETHER-OS targets the gap: the power user who wants local-first privacy \textbf{and} built-in AI \textbf{and} a real OS feel, without paying \$20/user/month to a cloud provider.

\section{Licensing Architecture}
% =========================================================

\subsection{System: Keylight (Rust-native, Ed25519)}

\begin{itemize}[noitemsep]
  \item Ed25519 signed offline leases --- no network call to validate
  \item Machine-bound activation (device fingerprinting)
  \item Offline grace period (7 days configurable)
  \item Tauri v2 plugin with TypeScript bindings
  \item Entitlement-based feature gating
\end{itemize}

\subsection{Flow}

\begin{verbatim}
Purchase -> Lemon Squeezy webhook -> Keylight API -> license key emailed
-> User enters key in AETHER-OS -> Online activation -> Signed lease in keychain
-> Local Ed25519 verify on every launch -> Offline >7d -> graceful Free tier
\end{verbatim}

\subsection{Critical Path Tests (Must pass before release)}

\begin{enumerate}[noitemsep]
  \item First-run onboarding completes successfully
  \item Create vault $\to$ add note $\to$ edit note $\to$ save $\to$ verify on disk
  \item AI chat with streaming $\to$ save conversation $\to$ verify in memory store
  \item Semantic search returns relevant results after indexing
  \item Project scan finds git repos $\to$ open in editor works
  \item License activation (Pro) $\to$ entitlement-gated features unlock
  \item App update $\to$ download $\to$ install $\to$ relaunch $\to$ new version
  \item Cross-platform: all above on macOS, Linux, Windows
\end{enumerate}

\subsection{Parallelization Rules}

\begin{itemize}[noitemsep]
  \item Never have two AIs edit the same file simultaneously
  \item Backend and frontend can be developed in parallel
  \item Define IPC contract (command names + types) FIRST, then parallelize
  \item Daily merge: integrate, run full test suite, fix conflicts
\end{itemize}

\subsection{Quality Gates}

Every AI-generated code must:
\begin{enumerate}[noitemsep]
  \item Pass \texttt{cargo clippy} with zero warnings
  \item Pass \texttt{cargo test} for affected modules
  \item Pass \texttt{npm run build} (TypeScript strict)
  \item Pass \texttt{npm test} for affected components
  \item Be reviewed by human (Ekin) before merge to main
\end{enumerate}
