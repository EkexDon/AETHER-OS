# Changelog

All notable changes to AETHER-OS are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [Semantic Versioning](https://semver.org/). The "What's new" dialog
in the app shows the section of the running version (or "Unreleased" in
development builds), so keep each entry short and user-facing.

## Unreleased

### Added

- First-run setup: a guided wizard that connects or creates a vault,
  checks Ollama, recommends and downloads a model for your machine, sets
  up semantic search and tours the most important shortcuts.
- Settings are now complete: General, Vault, AI Providers, Editor,
  Appearance, Shortcuts, Data & Privacy, Updates and About.
- "Ollama offline" and "model missing" guidance with copyable commands and
  one-click model downloads with live progress.
- Update check with release notes, an optional daily check on launch, and
  this "What's new" note after every update.
